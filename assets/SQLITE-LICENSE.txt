SQLite driver and linked Go dependency notices
=============================================

This file accompanies the router's compiled Go binaries. It contains the
unmodified license texts (normalized to LF) for the pinned driver and all
modules required by go.mod, including platform-specific dependencies, embedded
third-party libc/memory notices, SQLite's public-domain statement, and the Go
runtime. The official desktop application has its own notices and terms.

Module versions below match go.mod. Review and refresh these texts from the
corresponding module source whenever those versions change. A module may have
multiple sections when it ships additional applicable upstream notices.
